# neural-abm v0.1.0a2

`v0.1.0a2` is an alpha release for Git-based installation. It is not a final
release.

## Install

Default lightweight profile:

```bash
uv pip install "neural-abm @ git+https://github.com/kimyoungjin06/neural-abm.git@v0.1.0a2"
```

Torch-backed lifecycle API:

```bash
uv pip install "neural-abm[torch] @ git+https://github.com/kimyoungjin06/neural-abm.git@v0.1.0a2"
```

Research/full profiles:

```bash
uv pip install "neural-abm[research] @ git+https://github.com/kimyoungjin06/neural-abm.git@v0.1.0a2"
uv pip install "neural-abm[full] @ git+https://github.com/kimyoungjin06/neural-abm.git@v0.1.0a2"
```

## Highlights

- Lowered the package support floor to Python 3.11+.
- Kept the default package profile lightweight: only `numpy` and `pyyaml`.
- Preserved `torch` behind explicit `torch`, `research`, and `full` extras.
- Added `api_lite` as the torch-free surface for toy catalog, feature taxonomy,
  lightweight lifecycle reports, and NumPy social helpers.
- Kept `neural_abm.api` as the stable torch-backed v0 lifecycle facade.
- Built release inspection around wheel/sdist metadata rather than source-tree
  assumptions.

## Validation

Local validation before release:

- `uv run pytest -q` passed with 982 tests.
- `uv run ruff check src tests scripts` passed.
- `uv run python scripts/inspect_release_artifacts.py --build` passed with no
  blocking issues or warnings.
- Git install smoke on Python 3.11 confirmed:
  - `version=0.1.0a2`;
  - `Requires-Python=>=3.11`;
  - installed default packages are `neural-abm`, `numpy`, and `pyyaml`;
  - `torch_installed=false`;
  - `torch_loaded=false`.

## Known Boundaries

- This is an alpha release.
- `neural_abm.api_lite` is the no-torch package surface.
- `neural_abm.api`, `NABMUnit`, `NABMStep`, and `SocialBlock` are torch-backed.
- Toy IDs such as `toy1` through `toy10` remain stable reproducibility IDs;
  user-facing selection should use the feature-taxonomy catalog fields.
