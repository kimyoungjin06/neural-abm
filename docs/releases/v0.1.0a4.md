# neural-abm v0.1.0a4

`v0.1.0a4` is a clone-first Git alpha release for early users. The release unit
is the repository tag, and the intended first command path is a fresh clone with
`uv`.

## What Changed

- Added `examples/first_run.py` as the first post-clone smoke.
- Moved the README Quick Start ahead of project-map and scope material.
- Updated GitHub Actions to Node 24 compatible action versions.
- Added `docs/early-git-user-handoff.md` for stable, torch-backed, and
  experimental surface boundaries.
- Removed package upload automation and planning from the active release path.
- Included the first-run example and early handoff in the source distribution
  boundary.

## User Path

```bash
git clone --depth 1 --branch v0.1.0a4 https://github.com/kimyoungjin06/neural-abm.git neural-abm
cd neural-abm
uv run --no-dev python examples/first_run.py
uv run --no-dev python examples/toy_catalog.py
```

Pass criteria:

- `examples/first_run.py` reports `status=ok`.
- `toy_count=10`.
- `torch_loaded=false`.
- Package metadata and `neural_abm.__version__` both report `0.1.0a4`.

## Direct Git Tag Install

```bash
uv pip install "neural-abm @ git+https://github.com/kimyoungjin06/neural-abm.git@v0.1.0a4"
```

Use the optional extras only when needed:

```bash
uv pip install "neural-abm[torch] @ git+https://github.com/kimyoungjin06/neural-abm.git@v0.1.0a4"
uv pip install "neural-abm[research] @ git+https://github.com/kimyoungjin06/neural-abm.git@v0.1.0a4"
uv pip install "neural-abm[full] @ git+https://github.com/kimyoungjin06/neural-abm.git@v0.1.0a4"
```

## Validation

Before tagging, run:

```bash
uv run ruff check src tests scripts examples
uv run pytest -q
git diff --check
uv run python scripts/inspect_release_artifacts.py --build
uv run python scripts/smoke_package_profiles.py --profiles default
uv run --no-dev python examples/first_run.py
uv run --no-dev python examples/toy_catalog.py
```

After tagging, verify:

- CI passes on `main`.
- CI passes on `v0.1.0a4`.
- The CI step `Smoke clone-first default environment` passes.
- A fresh remote clone of `v0.1.0a4` runs the no-dev first-run and catalog
  examples.
- A direct Git URL install from `v0.1.0a4` reports version `0.1.0a4`,
  `toy_count=10`, and no torch import in the default profile.
