# neural-abm v0.1.0a6

`v0.1.0a6` is a clone-first Git alpha release for early users. The release unit
is the repository tag, and the intended first command path is a fresh clone of
that tag with `uv`. It is the first tag with the researcher-facing surfaces
that were accepted on `main` after `v0.1.0a5`.

## What Changed

- Added `neural_abm.scenario_lite`, torch-free bounded-scalar scenario
  comparison through `neural_abm.api_lite`, including seed-paired replicated
  runs with outcome distributions
  ([Decision 0015](../decisions/0015-researcher-scenario-lite-contract.md)).
  A returned `success` value records only that a user-provided threshold was
  met; it is not a judgment that a scientific claim is supported.
- Added `neural_abm.policy_scoring`, torch-free scoring of agent policies on
  held-out data, with a declared-unit leak check
  ([Decision 0016](../decisions/0016-out-of-sample-policy-scoring-contract.md)).
- Added the policy-ladder primitives
  ([Decision 0017](../decisions/0017-policy-ladder-semantics-extraction.md)):
  the torch-free `neural_abm.policy_ladder` (prior rule, keyed randomness,
  exploration floor, ordered outcome record, and prior-boosted trees, which
  import scikit-learn on first use) and the torch-backed residual learners in
  `neural_abm.policy_learners`, under the `torch` extra.
- Added the examples `examples/research_pivot_scenario_lite.py`,
  `examples/research_pivot_study.py`,
  `examples/research_pivot_learning_study.py`, and
  `examples/classical_reductions.py`, with the researcher-pivot case study and
  the classical-reductions note in the source distribution.
- Kept the default dependency boundary: the default profile neither installs
  nor loads `torch`.

## User Path

```bash
git clone --depth 1 --branch v0.1.0a6 https://github.com/kimyoungjin06/neural-abm.git neural-abm
cd neural-abm
uv run --no-dev python examples/first_run.py
uv run --no-dev python examples/toy_catalog.py
uv run --no-dev python examples/research_pivot_scenario_lite.py
```

Pass criteria:

- `examples/first_run.py` reports `status=ok`.
- `toy_count=10`.
- `torch_loaded=false`.
- The researcher scenario reports `surface=neural_abm.scenario_lite` and
  `torch_loaded=false`.
- Package metadata and `neural_abm.__version__` both report `0.1.0a6`.

## Direct Git Tag Install

```bash
uv pip install "neural-abm @ git+https://github.com/kimyoungjin06/neural-abm.git@v0.1.0a6"
```

Use the optional extras only when needed:

```bash
uv pip install "neural-abm[torch] @ git+https://github.com/kimyoungjin06/neural-abm.git@v0.1.0a6"
uv pip install "neural-abm[research] @ git+https://github.com/kimyoungjin06/neural-abm.git@v0.1.0a6"
uv pip install "neural-abm[full] @ git+https://github.com/kimyoungjin06/neural-abm.git@v0.1.0a6"
```

## Troubleshooting

If the user path fails, capture the diagnostics before changing branches,
installing extras, or modifying the environment:

```bash
uv --version
python --version
git rev-parse --short HEAD
uv run --no-dev python examples/first_run.py
uv run --no-dev python examples/toy_catalog.py
```

Open an early Git user report with the failed command, full output, operating
system, Python version, `uv --version`, attempted Git ref, and whether
torch-backed behavior was expected. The same intake path is documented in
`docs/early-git-user-handoff.md`.
