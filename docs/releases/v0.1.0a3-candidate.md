# neural-abm v0.1.0a3 Candidate

`v0.1.0a3` is the next proposed Git alpha tag. It has not been tagged yet.
This candidate records the current `main` direction after the package shifted
from package-index preparation back to clone-first onboarding.

## Candidate Purpose

This alpha should make the first user path:

```bash
git clone https://github.com/kimyoungjin06/neural-abm.git
cd neural-abm
uv run --no-dev python examples/toy_catalog.py
```

The Git URL install path remains supported for dependency-style use, but it is
not the first onboarding step before PyPI.

## Candidate Highlights

- README Quick Start now starts with a fresh clone and no-dev catalog smoke.
- `docs/git-distribution-flow.md` records the fresh clone contract.
- CI package-boundary checks include `Smoke clone-first default environment`.
- Default alpha usage remains lightweight and torch-free through
  `neural_abm.api_lite`.
- TestPyPI/PyPI publishing remains deferred until the Git alpha path is stable.

## Candidate Validation

Run these checks before creating `v0.1.0a3`:

```bash
uv run ruff check src tests scripts
uv run pytest -q
git diff --check
uv run python scripts/inspect_release_artifacts.py --build --ephemeral
uv run python scripts/smoke_package_profiles.py --profiles default
```

Also verify a fresh remote clone:

```bash
tmpdir=$(mktemp -d)
git clone --depth 1 https://github.com/kimyoungjin06/neural-abm.git "$tmpdir/neural-abm"
cd "$tmpdir/neural-abm"
uv run --no-dev python examples/toy_catalog.py
```

Pass criteria:

- CI is green on the candidate commit.
- `toy_catalog.py` reports `toy_count=10`.
- The default path does not install or load `torch`.
- `neural_abm.__version__` still matches package metadata.
- `pyproject.toml` is intentionally bumped to `0.1.0a3` before the tag is cut.

## Known Boundaries

- This is still an alpha candidate, not a final release.
- The package version remains `0.1.0a2` until `pyproject.toml` is intentionally
  bumped. Do not tag `v0.1.0a3` while package metadata still says `0.1.0a2`.
- PyPI and TestPyPI publishing are not complete.
- `neural_abm.api_lite` is the no-torch package surface.
- `neural_abm.api`, `NABMUnit`, `NABMStep`, and `SocialBlock` are torch-backed.
