# neural-abm v0.1.0a5

`v0.1.0a5` is a clone-first Git alpha release for early users. The release unit
is the repository tag, and the intended first command path is a fresh clone of
that tag with `uv`.

## What Changed

- Promoted the verified tag clone command to the first README, handoff, issue
  template, and release-note path.
- Added maintainer-side early Git reproduction tooling for fresh clone and
  direct Git tag install reports.
- Added early Git triage labels and a maintainer checklist for support routing.
- Kept `scripts/reproduce_early_git.py` maintainer-only and out of the source
  distribution boundary.
- Kept package upload automation and planning outside the active release path.

## User Path

```bash
git clone --depth 1 --branch v0.1.0a5 https://github.com/kimyoungjin06/neural-abm.git neural-abm
cd neural-abm
uv run --no-dev python examples/first_run.py
uv run --no-dev python examples/toy_catalog.py
```

Pass criteria:

- `examples/first_run.py` reports `status=ok`.
- `toy_count=10`.
- `torch_loaded=false`.
- Package metadata and `neural_abm.__version__` both report `0.1.0a5`.

## Direct Git Tag Install

```bash
uv pip install "neural-abm @ git+https://github.com/kimyoungjin06/neural-abm.git@v0.1.0a5"
```

Use the optional extras only when needed:

```bash
uv pip install "neural-abm[torch] @ git+https://github.com/kimyoungjin06/neural-abm.git@v0.1.0a5"
uv pip install "neural-abm[research] @ git+https://github.com/kimyoungjin06/neural-abm.git@v0.1.0a5"
uv pip install "neural-abm[full] @ git+https://github.com/kimyoungjin06/neural-abm.git@v0.1.0a5"
```

## Troubleshooting

If the user path fails, capture the diagnostics before changing branches,
installing extras, or modifying the environment:

```bash
uv --version
python --version
git rev-parse --short HEAD
uv run --no-dev python examples/first_run.py
uv run --no-dev python examples/toy_catalog.py
```

Open an early Git user report with the failed command, full output, operating
system, Python version, `uv --version`, attempted Git ref, and whether
torch-backed behavior was expected. The same intake path is documented in
`docs/early-git-user-handoff.md`.
