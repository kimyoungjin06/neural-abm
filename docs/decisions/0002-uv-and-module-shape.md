# Decision 0002: UV Environment and Module Shape

Status: Accepted

Date: 2026-04-29

## Context

The project will move from design documents to Python experiments. It needs a
standard environment manager and a conservative module boundary before Toy 1
implementation begins.

## Decision

Use `uv` for all Python environment and dependency management.

Project-level files:

- `.python-version`
- `pyproject.toml`
- `uv.lock`, generated by `uv sync`

Use Python 3.11 as the public package support floor. The package may be
developed and tested on newer interpreters, but `pyproject.toml` should not
require a newer Python unless source syntax, standard-library usage, or
dependency wheels force that change.

Implement reusable logic as a Python package under:

```text
src/neural_abm/
```

Use thin scripts under:

```text
scripts/
```

Initial module boundary:

```text
config.py
core.py
graphs.py
logging.py
metrics.py
mixers.py
toy_classification.py
toy_pd.py
```

## Consequences

- Experiment commands should be run with `uv run`.
- Dependencies should be changed through `pyproject.toml` and synchronized with
  `uv sync`.
- Python floor changes should be constrained by scientific package wheel
  support, especially `torch`.
- The first implementation should target Toy 1 only.
- Toy 2 should reuse the same node, mixer, logging, and metric interfaces.
