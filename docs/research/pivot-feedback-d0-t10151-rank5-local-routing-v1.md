explicit hepatitis-C, HCV, hepacivirus, or non-A/non-B-hepatitis anchors;

accept nor reject lower bound reached `0.50`; the score and source diagnostics
also did not trigger an indexing anomaly. Candidate rule v2 therefore returns

content state, not semantic truth, historical topic validation, a selection
certificate, pivot classification, outcome result, model fit, or scientific
effect.
